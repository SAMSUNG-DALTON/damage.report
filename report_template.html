Report Template Automation

PROTOTYPE

사진 업로드 → 자동 분류 → 데이터 확인 → 엑셀 문서 생성 흐름을 확인하는 샘플입니다.

1

사진 업로드

라벨, B/L, 컨테이너, 손상 부위 사진을 한 번에 올려주세요. 순서는 상관없습니다.

＋
사진을 끌어다 놓거나, 클릭해서 선택하거나, Ctrl+V로 붙여넣기
JPG, PNG · 여러 장 동시 선택 가능 · 캡처/복사한 이미지를 Ctrl+V로 바로 추가
2

정보 추출

라벨·B/L 사진에서 품번, 수량, 컨테이너 번호 등을 자동으로 읽어옵니다.

사진을 먼저 업로드하고 분류를 완료하세요.
3

보고서 생성

확인된 데이터와 사진을 회사 양식(Non-confirming Materials Notification)에 맞춰 엑셀로 채워 넣습니다.

1

사진 업로드 RM DAMAGE REPORT

라벨 사진과 손상 부위 사진을 올려주세요. 라벨은 정보 추출에만 쓰이고, 엑셀에는 라벨 사진과 손상 부위 사진이 함께 들어갑니다.

＋
사진을 끌어다 놓거나, 클릭해서 선택하거나, Ctrl+V로 붙여넣기
JPG, PNG · 여러 장 동시 선택 가능
2

정보 추출

라벨 사진에서 품번 · Batch · Doc No. · 품명 · 수량을 자동으로 읽어옵니다.

사진을 먼저 업로드하고 분류를 완료하세요.
3

보고서 생성

확인된 데이터와 사진을 RM Damage Report 양식에 맞춰 엑셀(A4)로 만듭니다.

이 프로토타입은 데모용입니다. 사진 분류는 실제 예시 사진에서 관찰한 시각적 특징(컨테이너 벽면의 반복되는 세로 패턴, B/L 서류의 전면 텍스트 분포, 라벨의 중앙 집중형 정보)을 규칙으로 옮긴 것으로, 학습된 이미지 인식 모델은 아닙니다. 조명·각도·배경에 따라 오분류가 있을 수 있어 각 사진의 분류는 드롭다운으로 직접 수정할 수 있습니다. 추출된 값은 모두 샘플 데이터이며, 실제 서비스에서는 라벨 바코드·SAP·Cello 조회 결과로 대체됩니다.

추출된 데이터 확인

사진에서 자동으로 읽어온 값입니다. 생성 전에 틀린 값이 있으면 직접 고쳐주세요.
